# video-to-notes evals

## 文件说明

| 文件 | 用途 |
|------|------|
| `deterministic_grader.py` | 结构完整性检查（7 项 → 等级 A/B/C/D） |
| `rubric_grader.py` | 质量维度评分（4 维度 → 等级 A/B/C/D） |

## 运行方式

```bash
python3 deterministic_grader.py ~/documents/某笔记.md [标签]
python3 rubric_grader.py ~/documents/某笔记.md [标签]
```

## 判定标准

| 等级 | deterministic | rubric | 含义 |
|:----:|:------------:|:------:|------|
| **A** | ≥0.90 | ≥0.90 | 优秀：结构完整+可复习性高 |
| **B** | ≥0.75 | ≥0.75 | 良好：基本完整，略有欠缺 |
| **C** | ≥0.70 | ≥0.65 | 及格：关键要素不全 |
| **D** | <0.70 | <0.65 | 不合格：质量不足 |

### deterministic（7 项硬性指标）

1. 文件大小 ≥ 1KB
2. 包含思维导图（Mermaid 或 ASCII）
3. 有对比性内容（对比/vs/区别/选择 等）
4. 有指引性内容（推荐/适用场景/步骤 等）
5. 有总结段落（总结/摘要/关键要点 等）
6. 有章节划分（二级标题）
7. 有表格

### rubric（4 维度评分）

| 维度 | 权重 | 检查项 |
|------|:----:|--------|
| 完整性 | 30% | 标题、来源信息、章节数 ≥3 |
| 结构清晰度 | 30% | 思维导图、表格或列表、标题层级 |
| 准确性 | 20% | 无占位符、内容 ≥500 字 |
| 可复习性 | 20% | 概览/总结段、要点提炼、可操作内容 |

> 通用质量评估，不限文档类型。高于 0.7/0.65 为 pass。
